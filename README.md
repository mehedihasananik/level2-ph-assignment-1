Within this assignment I will be using code examples to demonstrate my knowledge of basic and more advanced TypeScript features. These include:

Functions:
Optional parameters, default values and return types.
Union Types:
Working with multiple data types.
Tuples:
Creating a structure for coordinates.
Generics:
Creating generic functions to use on arrays and object properties.
Interfaces:
Creating a structure for data and filtering course information.
Classes & Inheritance:
Understanding access modifiers, constructors and inheritance.
Asynchronous Programming:
Using promises, resolve, reject and setTimeout().
